# AI Assistance – Recipe Finder

## Overview

AI was used as a development assistant throughout the Recipe Finder project. The goal was to use AI to speed up development while still reviewing, testing, and understanding the generated code.

## How AI Was Used

1. **Project planning**
   - Suggested a simple React + TypeScript structure.
   - Helped identify the main features and reusable components.

2. **UI development**
   - Helped create the initial Recipe Finder interface.
   - Assisted with the RecipeCard and RecipeModal components.
   - Helped with responsive styling.

3. **API integration**
   - Helped integrate TheMealDB API.
   - Assisted with functions for searching recipes, retrieving recipe details, and loading categories.

4. **Feature development**
   - Assisted with recipe search.
   - Assisted with displaying recipe details.
   - Assisted with implementing favourites using browser localStorage.

5. **Debugging and improvement**
   - AI was used to explain errors and suggest fixes when problems were found.
   - Generated code was tested in the browser before accepting it.

## Validation and Review

I did not blindly copy and accept AI-generated code. After each major implementation step, I ran the application and tested the features manually. I checked the UI, API responses, search behaviour, recipe details, and favourites functionality.

When something did not work as expected, I reviewed the generated code and corrected or refined it.

## Conclusion

AI acted as a productivity and learning tool during development rather than replacing the developer's role. I remained responsible for testing the application, reviewing the generated code, making corrections, and deciding which suggestions to keep.
