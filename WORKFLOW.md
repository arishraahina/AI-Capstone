# AI Development Workflow Comparison

## Feature Built

I built an Account Settings page using HTML, CSS, and JavaScript. The page contains a form with Name and Email fields along with a Save button.

## Round 1: Vague Prompt Approach

In the first round, I used a simple prompt asking AI to create a settings page. The prompt did not include many specific requirements or detailed instructions.

The AI generated a basic working solution with:
- A settings form layout
- Name and email input fields
- A save button
- Basic styling

## Issues Found in Round 1

After reviewing the generated code, I identified some areas that needed improvement:

- Validation requirements were not clearly defined.
- Error messages were not detailed enough.
- Accessibility improvements such as proper labels needed more attention.
- Responsive behavior was not specifically considered.
- The code structure could be improved for better maintainability.

## Review Process

I reviewed the AI-generated output and compared it with the required feature expectations. I identified missing details and prepared a more specific prompt for the next iteration.

## Lessons Learned

The first round showed that a simple prompt can create a working result, but it may not cover all project requirements. Providing detailed instructions helps AI generate more complete and reliable solutions.

## Next Steps

In Round 2, I provided a detailed prompt with specific requirements for validation, responsiveness, accessibility, and code organization to improve the final implementation.
