# AI Development Workflow Comparison

## Feature Built
I built a responsive Settings page using HTML, CSS, and JavaScript. The page contains Name and Email input fields with validation, clear error messages, and responsive design for desktop and mobile devices.

## Round 1: Vague Prompt Approach

In the first round, I used a simple prompt asking AI to create a settings form. The generated code provided a basic working solution, but it lacked detailed requirements and needed improvements.

Issues found:
- Validation was not fully detailed.
- Error messages could be improved.
- Code structure needed better organization.
- Responsive behavior required more attention.

## Round 2: Detailed Prompt Approach

In the second round, I provided a detailed prompt with clear requirements:
- Create a form with Name and Email fields.
- Add proper labels for accessibility.
- Validate required fields.
- Validate email format.
- Display clear validation errors.
- Make the design responsive.
- Keep HTML, CSS, and JavaScript organized.

The output from the second round was more complete and aligned with the requirements.

## Improvements Observed

The second version improved:
- Code readability and organization.
- Form validation handling.
- User experience with better error messages.
- Responsive layout across different screen sizes.

## AI Review and Verification

After generating the code, I reviewed the output and checked whether all requirements were satisfied. I tested the form behavior, checked validation cases, and verified that the page worked correctly on different screen sizes.

This exercise helped me understand that detailed prompts with clear constraints produce better AI-generated results compared to vague instructions.
